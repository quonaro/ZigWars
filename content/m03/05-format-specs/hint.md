Нужна одна строка: `alloc.print(fmt, args)` — выделяет буфер и возвращает `![]u8`. Спецификаторы: `{s}` для имени, `{d}` для возраста, `{d:.2}` для счёта.

---

```zig
return alloc.print("{s}, {d} лет, счёт {d:.2}", .{ name, age, score });
```

---

Проверь тесты на округление: `0.125` → `0.13`, а `100` → `100.00` — именно `{d:.2}` даёт фиксированные два знака после точки.
