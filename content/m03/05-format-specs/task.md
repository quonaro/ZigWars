## Задание

Реализуй `fmtUser` — карточку пользователя одной форматной строкой.

```zig
pub fn fmtUser(alloc: std.mem.Allocator, name: []const u8, age: u8, score: f64) ![]u8
```

Формат результата — строго:

```
<имя>, <возраст> лет, счёт <очки с 2 знаками>
```

### Примеры

| Вызов | Результат |
|-------|-----------|
| `fmtUser(a, "Даня", 25, 98.5)` | `"Даня, 25 лет, счёт 98.50"` |
| `fmtUser(a, "Аня", 30, 100)` | `"Аня, 30 лет, счёт 100.00"` |
| `fmtUser(a, "Zig", 1, 0.125)` | `"Zig, 1 лет, счёт 0.13"` — округление |

Используй `alloc.print` со спецификаторами `{s}`, `{d}` и `{d:.2}`. Возвращаемый слайс освобождает вызывающий.

Склонение «лет» не нужно — всегда «лет», даже для 21.
