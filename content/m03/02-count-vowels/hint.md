Пройди `for (s) |byte|` по байтам и увеличивай счётчик, когда байт — одна из пяти строчных гласных. Одинарные кавычки: `'a'` — байт, `"a"` — строка.

---

`switch` — выражение, его можно прибавить прямо к счётчику:

```zig
count += switch (byte) {
    'a', 'e', 'i', 'o', 'u' => 1,
    else => 0,
};
```

---

Полное решение — собери цикл из предыдущей подсказки и верни `count`. Альтернатива без `switch`: проверять `std.mem.findScalar(u8, "aeiou", byte) != null` — ищет байт в наборе.
