# Строка — это слайс байтов

## Никакого `string`

В Zig **нет типа «строка»**. Строка — это слайс байтов `[]const u8`. По соглашению байты обычно в UTF-8, но язык этого не гарантирует и не проверяет: `[]const u8` — просто указатель плюс длина. Русские буквы в UTF-8 занимают по два байта, так что `"Даня".len` — это **8**, а не 4.

```zig
const s: []const u8 = "zig";
s.len      // 3 — количество БАЙТ, не символов
s[0]       // 'z' — байт типа u8
```

## Строковые литералы

Литерал `"zig"` имеет тип `*const [3:0]u8` — указатель на массив из трёх байт с невидимым нулём в конце (sentinel, для совместимости с C). Он бесплатно «косится» в `[]const u8`, так что обычно о типе литерала можно не думать. Живут литералы в памяти программы — возвращать на них слайсы безопасно.

Многострочная строка — без кавычек и переводов строк, каждая строка начинается с `\\`:

```zig
const poem =
    \\первая строка
    \\вторая строка
;
// poem == "первая строка\nвторая строка"
```

## Сравнение: `==` не работает

Оператор `==` на слайсах сравнивает **указатели**, а не содержимое — почти всегда не то, что нужно (компилятор вообще откажется для `[]const u8`, если не очевидно, что ты сравниваешь адреса). Содержимое сравнивают так:

```zig
std.mem.eql(u8, "cat", "cat")        // true
std.mem.eql(u8, "cat", "car")        // false
std.mem.startsWith(u8, s, "he")      // префикс
std.mem.endsWith(u8, s, ".zig")      // суффикс
```

## Индексация и края

`s[i]` — байт по индексу. Выход за границу — `index out of bounds` (паника в Debug/ReleaseSafe, UB в ReleaseFast — не проверяй на прочность). Пустая строка `""` — валидный слайс с `len == 0`; обращение `s[0]` к ней упадёт. Перед индексацией проверяй `s.len`, либо используй API вроде `std.mem.startsWith`, который длину учитывает сам.

## Опциональные значения `?u8`

Функция «последний байт» не может вернуть байт для пустой строки. Честный ответ — **опционал** `?u8`: либо значение, либо `null`. Достать значение — `orelse`, `if (opt) |v|`, или `opt.?` (если точно есть).

```zig
const last: ?u8 = if (s.len == 0) null else s[s.len - 1];
if (last) |v| { /* v — u8 */ }
```
