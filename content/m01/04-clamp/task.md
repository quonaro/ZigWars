## Задание

Реализуй `clamp` **вручную** (без `std.math`): если `x < lo` вернуть `lo`, если `x > hi` вернуть `hi`, иначе `x`.

```zig
pub fn clamp(x: i32, lo: i32, hi: i32) i32
```

### Примеры

| Вызов | Результат |
|-------|-----------|
| `clamp(5, 0, 10)` | `5` |
| `clamp(-3, 0, 10)` | `0` |
| `clamp(15, 0, 10)` | `10` |
| `clamp(7, 7, 7)` | `7` |

Гарантируется `lo <= hi`. Можно решить одной строкой через вложенные `if`-выражения — попробуй.
