# Builtin-функции и `std.math`

## Builtins — функции с `@`

Zig держит язык маленьким: вместо ключевых слов для каждой мелочи есть **builtins** — встроенные функции компилятора, начинающиеся с `@`:

```zig
@min(a, b)        // минимум
@max(a, b)        // максимум
@abs(x)           // модуль
@intCast(x)       // приведение целых с проверкой (результат — целевого типа по контексту)
@floatFromInt(x)
@intFromFloat(x)
@clz(n)           // leading zeros — и десятки других
```

Уже встречавшиеся `@rem`, `@mod` — оттуда же. Полный список — в langref, их ~100, но зубрить не надо: подсвечиваются отдельным цветом, сигнатуры читаются прямо из ошибок компилятора.

## Явные приведения типов

Zig **не приводит типы молча**:

```zig
const a: i32 = 5;
const b: u8 = a;          // ошибка компиляции!
const b: u8 = @intCast(a); // так — ок, но упадёт в Debug если a не влезает
```

Расширение «в больший» тип (`u8` → `i32`) безопасно и разрешено автоматически. Сужение — только явно.

## `std.math`

Стандартная библиотека: `std.math.clamp(x, lo, hi)`, `std.math.min`, `std.math.maxInt(T)`, `std.math.pow`…

```zig
const std = @import("std");
const c = std.math.clamp(15, 0, 10); // 10
```

В этом kata — реализуй clamp **сам**, без `std.math` — чтобы почувствовать `if`-выражение.
