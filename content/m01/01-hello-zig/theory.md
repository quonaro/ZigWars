# Добро пожаловать в Zig

Zig — системный язык программирования: компилируемый, быстрый, без сборщика мусора и без скрытых аллокаций. Код на нём читается почти как C, но с современными фичами и без C-шных ловушек.

## Как устроен этот тренажёр

Каждое задание (kata) — это функция, которую нужно реализовать. Справа два редактора: **Решение** (`solution.zig`) и **Тесты** (`tests.zig`). Кнопка **ТЕСТ** (или `Ctrl+Enter`) компилирует и запускает тесты — `zig test` проверяет твой код.

## Функции

```zig
const std = @import("std");

pub fn square(x: i32) i32 {
    return x * x;
}
```

- `pub` — делает функцию видимой из других файлов (тесты импортируют твой `solution.zig`, поэтому функции должны быть `pub`).
- `fn имя(аргумент: тип) тип_результата { ... }`
- Типы целых: `i8`, `i16`, `i32`, `i64`, `u8`…`u64`, `usize`. Плавающие: `f32`, `f64`. Логический: `bool` (`true`/`false`).

## Переменные

```zig
const a = 5;      // иммутабельная — как final/const, переприсвоить нельзя
var b = 5;        // мутабельная
b += 1;
```

Zig **очень любит** `const`: по умолчанию всё константы, `var` — только когда реально нужно.

## Тесты в Zig

Встроены прямо в язык — специальный блок `test`:

```zig
test "квадрат двойки" {
    try std.testing.expectEqual(4, square(2));
}
```

`expectEqual(ожидаемое, фактическое)` — ожидаемое значение идёт **первым** аргументом.
