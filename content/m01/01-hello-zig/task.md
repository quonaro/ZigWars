## Задание

Реализуй функцию `add`, которая принимает два числа `i32` и возвращает их сумму.

```zig
pub fn add(a: i32, b: i32) i32 {
    // твой код
}
```

### Примеры

| Вызов | Результат |
|-------|-----------|
| `add(2, 3)` | `5` |
| `add(-1, 1)` | `0` |
| `add(0, 0)` | `0` |

Нажми **ТЕСТ**, когда будешь готов. Если видишь ошибки компиляции — читай их внимательно, компилятор Zig говорит довольно точно, что не так.
