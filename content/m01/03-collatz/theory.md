# Циклы: `while` и `for`

## `while`

Классический цикл с условием — но с фишкой: **выражение продолжения** после `:`

```zig
var i: usize = 0;
while (i < 10) : (i += 1) {
    std.debug.print("{d}\n", .{i});
}
```

`while (условие) : (что сделать после каждой итерации) { тело }` — по сути `for(;;)` из C, только явнее. Можно и без `:` — обычный while.

Как и `if`, `while` — **выражение**: у него может быть `else`, который выполнится, если цикл ни разу не запустился.

## `for`

`for` в Zig работает **только по итерируемым**: массивам, слайсам. Не по «числам от A до B» — для этого while. Подробнее про массивы — в модуле 2, но вот пример:

```zig
const nums = [_]i32{ 1, 2, 3 };
for (nums) |item| {
    // item — элемент
}
for (nums, 0..) |item, idx| {
    // idx — индекс, 0.. — диапазон
}
```

Захват `|name|` — это пайп-синтаксис Zig: элементы «выгружаются» в именованные переменные.

## `break`, `continue` и значение из цикла

```zig
while (true) {
    if (done) break;
}
```

`break` может вернуть **значение**:

```zig
const result = while (x > 0) : (x -= 1) {
    if (x == 5) break x * 2;
} else 0;   // else — если break не сработал
```

## Таймауты тренажёра

Здесь циклы выполняются реально — бесконечный `while (true)` съест лимит в 20 секунд и тест «умрёт». Проверяй условия выхода!
