# Биты и сдвиги

## Побитовые операторы

```zig
a & b    // AND
a | b    // OR
a ^ b    // XOR
~a       // NOT (инверсия)
a << 3   // сдвиг влево
a >> 3   // сдвиг вправо
```

Сдвиги строгие: правый операнд должен быть беззнаковым и «знать» разрядность. Чаще всего пишут `x >> @intCast(k)` или используют `u5`/`u6` для количества бит (для 32/64-битных типов).

## Битовые литералы

```zig
const flags = 0b1010;        // двоичный
const mask = 0xFF;           // шестнадцатеричный
const spaced = 0b1010_1100;  // подчёркивания для читаемости
```

## Полезные builtins для битов

```zig
@popCount(x)      // число единичных бит
@ctz(x)           // нули справа (trailing zeros)
@clz(x)           // нули слева (leading zeros)
@bitSizeOf(T)     // разрядность типа
```

Эта задача — классический «Brian Kernighan trick»: `x & (x - 1)` снимает младший единичный бит за одну операцию. Посчитай, сколько раз можно это сделать, пока `x` не станет нулём — получишь ответ без builtin'ов.

## Почему это важно

Zig — системный язык: протоколы, флаги, упакованные структуры (`packed struct`), драйверы — всё через биты. Умение читать `x & (1 << k)` — базовая грамотность.
