# Булевы значения и остаток от деления

## `bool` и сравнения

```zig
const x: bool = 5 > 3;    // true
x == true                 // равенство — двойное ==
5 != 3                    // неравенство
```

Логические операторы — **слова**, а не символы:

```zig
if (a and b) { ... }
if (a or b) { ... }
if (!a) { ... }           // отрицание — восклицательный знак
```

## Остаток от деления: `%` в Zig нет!

В C/Python пишут `n % 2`. В Zig оператора `%` **нет** — вместо него два встроенных вызова (builtins):

```zig
@rem(a, b)   // остаток со знаком делимого: @rem(-7, 3) == -1
@mod(a, b)   // остаток со знаком делителя: @mod(-7, 3) == 2
```

Для положительных чисел они совпадают. Для проверки чётности обычно берут `@rem(n, 2) == 0` — короче в записи.

## `if` — это выражение

В Zig `if` возвращает значение, его можно присвоить:

```zig
const label = if (n > 0) "positive" else "non-positive";
const abs = if (x < 0) -x else x;
```

Блоки тоже работают:

```zig
pub fn isEven(n: i32) bool {
    if (@rem(n, 2) == 0) {
        return true;
    }
    return false;
}
```

> **Заметь**: условие в `if` — строго `bool`. `if (n)` не скомпилируется — в Zig нет неявного приведения чисел к булеву. Это осознанное решение: меньше магии — меньше багов.
