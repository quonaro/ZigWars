## Задание

Реализуй `dupSlice` — копию среза `i32` в свежую память из переданного аллокатора.

```zig
pub fn dupSlice(alloc: std.mem.Allocator, xs: []const i32) ![]i32
```

### Правила

- Вернувшийся срез принадлежит вызывающему — тест освободит его через `alloc.free`.
- Пустой вход → пустой срез (это не ошибка).
- Не мутируй `xs` — он `const`.

### Примеры

| Вход | Результат |
|------|-----------|
| `[1, 2, 3]` | новый срез `[1, 2, 3]` |
| `[]` | пустой срез |
| `[-5, 0, 7]` | `[-5, 0, 7]` — но другой адрес! |

В теории есть нужный метод аллокатора из четырёх букв.
