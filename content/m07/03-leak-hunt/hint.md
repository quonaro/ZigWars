Посмотри на `tmp`: он выделяется, используется для сортировки, а потом о нём забывают. Функция возвращает `out`, а `tmp` остаётся висеть в памяти — и на пути успеха, и при ошибке.

---

Временному буферу нужен `defer` — он живёт только внутри функции и должен умереть при любом выходе. Результату `errdefer` не нужен: после его выделения нет операций, которые могли бы вернуть ошибку.

---

```zig
const tmp = try alloc.dupe(i32, xs);
defer alloc.free(tmp);   // ← вот эта строка решает всё
```
