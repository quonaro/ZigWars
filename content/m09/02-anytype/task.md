## Задание

Две дженерик-функции на `anytype`.

### `maxOf`

```zig
pub fn maxOf(a: anytype, b: @TypeOf(a)) @TypeOf(a)
```

Возвращает большее из двух значений **одного типа** (любого сравнимого: целые, числа с плавающей точкой). Второй параметр привязан к типу первого — `maxOf(3, 4.5)` не скомпилируется, и это правильно.

### `add`

```zig
pub fn add(a: anytype, b: anytype) @TypeOf(a, b)
```

Сумма двух значений **разных, возможно, типов**. Результат — общий тип пары (`@TypeOf(a, b)` решает peer type resolution).

### Примеры

| Вызов | Результат | Тип |
|-------|-----------|-----|
| `maxOf(@as(i32, 3), @as(i32, 7))` | `7` | `i32` |
| `maxOf(@as(f64, 2.5), @as(f64, -1))` | `2.5` | `f64` |
| `add(@as(i32, 1), @as(i32, 2))` | `3` | `i32` |
| `add(@as(u8, 200), @as(u16, 100))` | `300` | `u16` |
| `add(@as(i32, 1), @as(f64, 0.5))` | `1.5` | `f64` |

### Ограничения

- Не сравнивай типы вручную и не используй `if` по типу — `@TypeOf` и арифметика Zig сделают всё сами.
- Для `maxOf` подойдёт тернарный `if (a > b) a else b` — Zig вернёт `if` как выражение.
