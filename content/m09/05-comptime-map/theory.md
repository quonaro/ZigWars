# Таблицы вместо вычислений и @compileError

## Comptime-таблицы

Если значение нужно часто, а считать его дорого — посчитай один раз при компиляции и положи в массив. Компилятор исполнит код и запишет в бинарник готовую таблицу:

```zig
const fib_table = blk: {
    var t: [93]u64 = undefined;
    t[0] = 0;
    t[1] = 1;
    for (2..93) |i| t[i] = t[i - 1] + t[i - 2];
    break :blk t;
};

pub fn fib(comptime n: u8) u64 {
    return fib_table[n];
}
```

Инициализатор `const` на уровне файла и так исполняется в comptime — отдельное слово `comptime` было бы лишним (компилятор выдаёт «redundant comptime keyword»). `fib(90)` — это чтение константы из массива, в бинарнике лежат уже готовые 93 числа.

Почему 93? `fib(92)` — последнее число Фибоначчи, влезающее в `u64` (`fib(93)` уже переполняет). Практический comptime — это и про осознанные границы.

## Вариативность вместо перегрузок

В Zig **нет перегрузки функций** — одно имя, одна сигнатура. Вместо этого функция принимает тип как comptime-аргумент и ветвится по нему:

```zig
pub fn rangeSum(comptime T: type, comptime lo: T, comptime hi: T) T {
    // T может быть i8, i32, u64 — одна функция на всех
}
```

Вызов `rangeSum(i32, 1, 10)` передаёт три значения: тип и две константы. Все `comptime`-параметры известны при компиляции — функция инстанцируется под конкретную комбинацию.

## `@compileError` — стражи

Если дженерик вызвали с неподходящим типом, Zig покажет ошибку где-то внутри — глубоко и непонятно. `@compileError` останавливает компиляцию с твоим сообщением:

```zig
pub fn rangeSum(comptime T: type, comptime lo: T, comptime hi: T) T {
    switch (@typeInfo(T)) {
        .int => {},
        else => @compileError("rangeSum: нужен целочисленный тип, а не " ++ @typeName(T)),
    }
    // ...
}
```

Ставь стражи **в начале** функции — пользователь увидит внятное «нужен целый тип, а не f64», а не цепочку ошибок в теле.

Проверить `@compileError` юнит-тестом нельзя (ошибка компиляции — не исключение) — только вручную или через `zig build test` с ожидаемой ошибкой. Но тесты на валидных входах косвенно подтверждают, что страж не срабатывает ложно.

## Шаблон проектирования

```zig
pub fn myGeneric(comptime T: type, /* ... */) ReturnType {
    // 1. стражи
    switch (@typeInfo(T)) { ... => @compileError("...") }
    // 2. ветвление по типу при необходимости
    // 3. основная логика — обычный код, T подставлен
}
```
