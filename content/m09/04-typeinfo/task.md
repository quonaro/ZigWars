## Задание

Реализуй `describe` — comptime-функцию, которая возвращает строковое описание типа.

```zig
pub fn describe(comptime T: type) []const u8
```

### Формат вывода

| `T` | Результат |
|-----|-----------|
| `i32`, `i8`, `isize` | `"знаковое целое, N бит"` — N = разрядность |
| `u8`, `u64`, `usize` | `"беззнаковое целое, N бит"` |
| `f32`, `f64` | `"число с плавающей точкой, N бит"` |
| `bool` | `"логический"` |
| `[]u8`, `[]const u8` | `"слайс на {имя элемента}"` — например `"слайс на u8"` |
| `*u8`, `*const i32` | `"указатель на {имя типа}"` — например `"указатель на u8"` |
| всё остальное | `"другое: {имя типа}"` — например `"другое: void"` |

Имена типов бери из `@typeName(...)`, числа — из полей `@typeInfo`. Собирай строки через `std.fmt.comptimePrint`.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `describe(i32)` | `"знаковое целое, 32 бит"` |
| `describe(u8)` | `"беззнаковое целое, 8 бит"` |
| `describe(f64)` | `"число с плавающей точкой, 64 бит"` |
| `describe(bool)` | `"логический"` |
| `describe([]const u8)` | `"слайс на u8"` |
| `describe(*i32)` | `"указатель на i32"` |
| `describe(struct{x:i32})` | `"другое: solution.…"` — имя зависит от контекста |

### Подсказки

- `switch (@typeInfo(T))` с тегами `.int`, `.float`, `.bool`, `.pointer`, `else`.
- В `.pointer` смотри `info.size`: `.slice` — это `[]T`, остальные размеры — обычные указатели.
- `usize` — это `.int` (беззнаковое, 64 бита на x86_64).
