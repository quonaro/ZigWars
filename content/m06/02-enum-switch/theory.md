# Перечисления и `switch`

## `enum` — конечный набор вариантов

```zig
const Dir = enum { north, east, south, west };

const d = Dir.east;
const e: Dir = .south; // тип известен — имя enum можно опустить
```

Это не «замаскированные числа» как в C. `Dir.north` — значение типа `Dir`, и присвоить ему `5` нельзя. Компилятор знает все варианты — и это главная фишка: он может **проверить, что ты рассмотрел каждый**.

Внутри у enum — целочисленный тег (по умолчанию самый маленький подходящий тип). Перевод туда-сюда — два builtin'а:

```zig
@intFromEnum(Dir.south)    // 2 — индекс в объявлении
@enumFromInt(3)            // Dir.west — тип из контекста, как и у @intCast
```

`@enumFromInt` — место, где живёт unsafe: индекс вне диапазона — неопределённое поведение (в Debug — паника). Для надёжности есть `std.meta.intToEnum`, но сейчас хватит builtin'ов.

## `switch` — исчерпывающий или с `else`

В Zig `switch` по enum **обязан покрыть все варианты**:

```zig
const deg = switch (d) {
    .north => 0,
    .east => 90,
    .south => 180,
    .west => 270,
};
```

Забыл `.west` — ошибка компиляции с перечислением пропущенных. Добавил в enum пятый вариант — все `switch`'и по нему перестанут компилироваться и заставят тебя пройтись по коду. Это один из главных источников уверенности при рефакторинге в Zig.

Не хочешь перечислять всё — `else` ловит остаток:

```zig
const isVertical = switch (d) {
    .north, .south => true,
    else => false,
};
```

## `switch` — это выражение

Как и `if`, `switch` возвращает значение — присваивай прямо в `const` (см. пример выше). Правая часть стрелки — тоже выражение, может быть блоком:

```zig
const n = switch (x) {
    0 => 1,
    else => blk: {
        // многострочная логика
        break :blk x * 2;
    },
};
```

## switch по целым и диапазоны

`switch` работает не только по enum — по целым, по `u8`-символам, и умеет диапазоны `a...z` (включительно с обеих сторон):

```zig
const kind = switch (c) {
    '0'...'9' => .digit,
    'a'...'z', 'A'...'Z' => .letter,
    '+', '-', '*', '/' => .operator,
    else => .other,
};
```

Диапазоны не должны пересекаться — компилятор ругнётся.

## Анонимный enum в параметре

Можно написать прямо в сигнатуре: `fn f(side: enum { left, right }) void`. Литералы `.left`/`.right` склеятся с этим типом при вызове `f(.left)`. Удобно для «флажков из двух вариантов», когда заводить именованный тип лень. Для публичного API обычно всё же называют.

## Labeled switch (на будущее)

Редкий, но забавный зверь: switch можно пометить меткой и `continue` в другой кейс:

```zig
const r = st: switch (state) {
    .start => continue :st .running,
    .running => break :st 42,
    else => unreachable,
};
```

Понадобится для конечных автоматов. Сейчас просто знай, что синтаксис `метка: switch` + `continue :метка значение` существует.
