## Задание

Мини-калькулятор на enum. Объявление дано — реализуй три функции.

```zig
pub const Op = enum { add, sub, mul, div,

    /// Символ операции: '+' , '-', '*', '/'.
    pub fn symbol(op: Op) u8

    /// Парсинг символа в операцию; незнакомый символ → null.
    pub fn fromChar(c: u8) ?Op
};

/// Применить операцию к a и b. Деление на 0 → null.
pub fn apply(op: Op, a: f64, b: f64) ?f64
```

- `apply(.div, x, 0)` должен вернуть `null` (проверяй `b == 0` до деления).
- `fromChar` принимает `'+', '-', '*', '/'`; любой другой байт → `null`.
- `symbol` возвращает ASCII-код символа.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `apply(.mul, 3, 4)` | `12.0` |
| `apply(.div, 1, 0)` | `null` |
| `Op.fromChar('-')` | `.sub` |
| `Op.fromChar('x')` | `null` |
| `Op.div.symbol()` | `'/'` |
