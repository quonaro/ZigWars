# `union(enum)` — тип-сумма

## Проблема: «либо круг, либо прямоугольник»

Фигура на экране — это *или* круг с радиусом, *или* прямоугольник с двумя сторонами, *или* квадрат со стороной. Держать в структуре все поля сразу (`radius`, `w`, `h`…) — расточительно и опасно: половина полей всегда «лишняя», а какая именно — надо помнить.

Нужен тип-сумма: значение занимает место под **самый большой** вариант + хранит тег, какой вариант сейчас активен. В Zig это `union(enum)` — **размеченное объединение** (tagged union):

```zig
const Shape = union(enum) {
    circle: f64,
    rect: struct { w: f64, h: f64 },
    square: f64,
};
```

Каждый вариант — имя тега + тип payload'а. Payload может быть любым типом, включая анонимную структуру, как у `rect`. Создание:

```zig
const s1 = Shape{ .circle = 2.0 };
const s2: Shape = .{ .rect = .{ .w = 3, .h = 4 } };
const s3: Shape = .{ .square = 5 };
```

## Чтение — только через `switch`

Получить payload без проверки тега нельзя — и это правильно. `switch` по тегу, значение захватывается через `|v|`:

```zig
const area = switch (s) {
    .circle => |r| std.math.pi * r * r,
    .rect => |rc| rc.w * rc.h,
    .square => |a| a * a,
};
```

Внутри стрелки `r` имеет тип `f64`, `rc` — тип анонимной структуры с полями `.w`, `.h`. Каждая ветка видит payload **своего** типа — полный паттерн-матчинг, как в Rust/OCaml, только без ключевого слова `match`.

Захват можно взять по указателю — для мутации:

```zig
switch (&s) {
    .circle => |*r| r.* *= 2, // увеличили радиус вдвое
    else => {},
}
```

(Обрати внимание на `&s` и `|*r|` — пара работает только вместе.)

## Активный тег — тоже значение

`std.meta.activeTag(s)` или просто `switch (s) { .circle => ... }` по имени — тег живёт в объединении и доступен. Если поля без payload (`void`), пишут `.none => {}`.

## Почему не обычный union

В Zig есть и «голый» `union` без тега — это unsafe-инструмент уровня C:

```zig
const Bits = union { i: i32, f: f32 }; // reinterpret битов
```

Он не помнит, какое поле записано последним: запишешь `.f`, прочитаешь `.i` — получишь мусорное переосмысление бит (и никакой ошибки). Нужен для FFI и побитовых трюков. **Для моделирования «одно из нескольких» — всегда `union(enum)`**: тег добавляет байт-два, но превращает UB в ошибку компиляции/панику.

Есть и промежуточный вариант `union(TagType)` — тег вынесен наружу, безопасности ноль. В проде встречается редко.

## `std.math.pi`

Для π импортируй `std` и бери `std.math.pi` — это `comptime_float`-константа, присвоится как `f64` безо всяких кастов.
