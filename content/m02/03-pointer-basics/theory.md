# Указатели

## `*T` — указатель на один элемент

Указатель в Zig пишется `*T` — адрес одного значения типа `T`. Взять адрес — `&x`, прочитать/записать значение по адресу — `ptr.*`:

```zig
var x: i32 = 10;
const p: *i32 = &x;   // p указывает на x
p.* += 5;             // разыменование + запись
// x == 15
```

Синтаксис `p.*` намеренно «шумный»: разыменование — важное событие, и Zig заставляет его видеть.

`*const T` — указатель «только читать»: `p.* = 5` не скомпилируется. `*T` неявно приводится к `*const T`, наоборот — нет.

## Зачем передавать указатель в функцию

Аргументы в Zig копируются. Хочешь, чтобы функция изменила твою переменную — передай адрес:

```zig
fn zero(p: *i32) void {
    p.* = 0;
}

var n: i32 = 42;
zero(&n);   // n == 0
```

Сравни с C: то же самое, только без указательной арифметики на `*T` — компилятор не даст сделать `p + 1` у одноэлементного указателя.

## Многоэлементный указатель `[*]T`

`[*]T` — «указатель на много элементов»: адрес, по которому лежит серия значений, но **без длины**. На нём работает арифметика `p + 1` и индексация `p[i]` — а следишь за границами сам ты. Это уровень C-интеропа и внутренней кухни слайсов.

| Тип | Что это | Арифметика | Знает длину |
|-----|---------|------------|-------------|
| `*T` | один элемент | нет | не нужна |
| `[*]T` | много элементов | да | **нет** |
| `[]T` | слайс | нет | да, `.len` |
| `*[N]T` | указатель на массив | нет | да, в типе |

## Слайс = указатель + длина

`[]T` — это буквально пара `(*T, usize)` упакованная в одно значение. Поэтому слайс «дешёвый»: передача его в функцию копирует 16 байт, а не данные. И поэтому `[]i32` можно резать: `xs[2..]` — тот же указатель, сдвинутый на 2, с длиной поменьше. Копий нет.

Из слайса можно достать голый указатель: `xs.ptr` — тип `[*]T`. Это то, что ты отдашь в C-функцию.

## Указатели в `for`

```zig
for (xs) |*elem| {
    elem.* += delta;   // меняет исходный слайс
}
```

`|*elem|` захватывает указатель на элемент — удобная альтернатива индексам, когда не нужна позиция.

## Правила безопасности

- Нет `void*` и неявных приведений: `*i32` в `*u32` сам не превратится (нужен `@ptrCast`).
- Нет арифметики на `*T`: `p + 1` — ошибка компиляции, используй `[*]T` или слайсы.
- Нулевых указателей «просто так» нет: `*T` никогда не null. Null выражается через `?*T` — optional-указатель, разыменовать который заставят только после проверки.
