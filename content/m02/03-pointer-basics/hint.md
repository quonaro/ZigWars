Чтобы прочитать/записать значение по указателю `*i32`, используй `a.*`. В `incAll` захвати элементы через `for (xs) |*x|`.

---

`swap` — классика с временной переменной: `const tmp = a.*; a.* = b.*; b.* = tmp;`

---

```zig
pub fn incAll(xs: []i32, delta: i32) void {
    for (xs) |*x| x.* += delta;
}
```
