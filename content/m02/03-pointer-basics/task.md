## Задание

Реализуй две функции:

```zig
pub fn swap(a: *i32, b: *i32) void
pub fn incAll(xs: []i32, delta: i32) void
```

- `swap` меняет местами значения по двум указателям.
- `incAll` прибавляет `delta` к каждому элементу слайса (delta может быть отрицательной).

### Примеры

| Код | Эффект |
|-----|--------|
| `x=1, y=2; swap(&x, &y)` | `x==2, y==1` |
| `incAll(&xs, 10)` на `[1,2]` | `xs == [11,12]` |
| `incAll(&xs, -3)` на `[5,5]` | `xs == [2,2]` |
| `incAll(&.{}, 7)` | пустой слайс — без паники |

Обе функции ничего не возвращают — весь эффект через указатели и слайс.
