## Задание

Реализуй `indexOfMax` — индекс **первого** максимального элемента слайса:

```zig
pub fn indexOfMax(xs: []const i32) ?usize
```

Вернёшь `?usize`: `null` для пустого слайса, иначе индекс.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `indexOfMax(&.{1, 9, 3})` | `1` |
| `indexOfMax(&.{5, 5, 5})` | `0` (первый из равных) |
| `indexOfMax(&.{-3, -1, -7})` | `1` |
| `indexOfMax(&.{42})` | `0` |
| `indexOfMax(&.{})` | `null` |

При равенстве максимумов бери **первый** — значит, обновлять `best` надо при строгом `>`, а не `>=`.
