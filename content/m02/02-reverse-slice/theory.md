# Мутабельные слайсы

## `[]const T` против `[]T`

В прошлой kata мы принимали `[]const i32` — «смотрю, но не трогаю». Чтобы менять элементы, сигнатура должна требовать `[]i32`:

```zig
fn double(xs: []i32) void {
    for (xs) |*x| x.* *= 2;  // *x — указатель на элемент
}
```

Обрати внимание: возвращать ничего не нужно. Слайс — это вид на чужую память: меняя `xs[i]`, ты меняешь исходный массив вызывающего. Это и есть «in place» — без выделения нового буфера.

```zig
var data = [_]i32{ 1, 2, 3 };
double(&data);
// data == .{ 2, 4, 6 }
```

`&data` — массив превращается в `[]i32`, только если сам `data` объявлен через `var`. От `const`-массива мутабельный слайс получить нельзя — компилятор защитит.

## Доступ по индексу

Запись через индекс выглядит как чтение:

```zig
xs[0] = 99;
xs[xs.len - 1] += 1;
const last = xs[xs.len - 1];  // осторожно с пустым слайсом!
```

## Идиома «два указателя»

Разворот на месте — классика: два индекса идут навстречу с концов, меняя элементы местами, пока не встретятся.

```
i →                ← j
[ 1, 2, 3, 4, 5 ]
  swap(0,4) → [ 5, 2, 3, 4, 1 ]
    swap(1,3) → [ 5, 4, 3, 2, 1 ]
      i == j → стоп
```

```zig
var i: usize = 0;
var j: usize = xs.len;  // j идёт ЗА последним элементом
while (i < j) {
    j -= 1;
    // swap xs[i], xs[j]
    i += 1;
}
```

Зачем `j` начинается с `len`, а не `len - 1`? Ради пустого слайса: у него `len == 0`, и `len - 1` — переполнение `usize` (паника в дебаге, огромное число в релизе). Вариант с `j = xs.len` и предекрементом `j -= 1` внутри цикла красиво обходит ловушку: условие `0 < 0` ложно, и мы даже не заходим внутрь.

## Swap руками

```zig
const tmp = xs[i];
xs[i] = xs[j];
xs[j] = tmp;
```

Или готовое `std.mem.swap(i32, &xs[i], &xs[j])` — принимает указатели на элементы (`&xs[i]` — адрес i-го элемента, про указатели подробно в следующей kata).

## Что не влезет в слайс

Развернуть слайс «по кругу», вставить элемент в середину, удлинить — нельзя: у слайса фиксированная длина и чужая память. Для этого нужны `std.ArrayList` и аллокатор — это совсем другой модуль.
