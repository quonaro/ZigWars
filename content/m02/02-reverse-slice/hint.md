Два индекса: `i` идёт от начала, `j` — от конца. Пока `i < j`, меняй `xs[i]` и `xs[j]` местами и сдвигай оба.

---

Не пиши `var j = xs.len - 1` — на пустом слайсе это переполнение. Хитрость: `var j = xs.len;` и `j -= 1` первой строкой внутри цикла.

---

```zig
var i: usize = 0;
var j: usize = xs.len;
while (i < j) {
    j -= 1;
    const tmp = xs[i];
    xs[i] = xs[j];
    xs[j] = tmp;
    i += 1;
}
```
