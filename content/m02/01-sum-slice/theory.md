# Массивы и слайсы

## Массив: размер — часть типа

Массив в Zig объявляется как `[N]T` — длина `N` зашита в тип и известна на этапе компиляции:

```zig
const a: [5]i32 = .{ 1, 2, 3, 4, 5 };
const b = [_]i32{ 1, 2, 3 };  // [_] — «выведи длину сам», получится [3]i32
var zeros: [10]u8 = .{0} ** 10;  // повторение: десять нулей
```

`a.len` — не поле в рантайме, а константа типа. Массивы разной длины — разные типы: `[3]i32` и `[4]i32` несовместимы.

Массив — значение: присваивание копирует его целиком, передача в функцию — тоже (если не через указатель).

## Слайс: указатель + длина

Чтобы писать функции, работающие с массивом *любой* длины, используют слайс `[]T` — толстый указатель из двух машинных слов: адрес первого элемента и `len`.

```zig
const arr = [_]i32{ 10, 20, 30, 40 };
const all: []const i32 = &arr;        // массив неявно превращается в слайс
const mid = arr[1..3];                // { 20, 30 }
const tail = arr[2..];                // до конца
const head = arr[0..2];               // { 10, 20 }
```

Слайс хранит *свою* длину: `mid.len == 2`. Брать слайс от слайса можно сколько угодно — выход за границы ловится проверками в Debug/ReleaseSafe и ломается тишиной в ReleaseFast (ещё один повод не выходить).

## `[]T` против `[]const T`

`[]const i32` — слайс «только читать». `[]i32` — «читать и писать». Мутабельный можно неявно отдать туда, где ждут const — наоборот нельзя. Правило: принимай `[]const T`, если функция не собирается ничего менять.

## Обход: `for`

```zig
for (xs) |x| {
    // x — копия элемента
}
for (xs) |*x| {
    x.* += 1;  // указатель на элемент — можно менять
}
for (xs, 0..) |x, i| {
    // x — элемент, i — индекс usize
}
```

Третья форма — замена `for (int i = 0; i < n; i++)` из C. `0..` — диапазон «от нуля до конца слайса».

## Пустой слайс

`&.{}` — пустой слайс-литерал. У него `.len == 0`, `for` по нему не выполнится ни разу — циклы по пустому слайсу безопасны сами собой. А вот `xs[0]` на пустом слайсе — паника.

## Индексация

`xs[i]` — элемент по индексу. Индекс — `usize`. Отрицательных индексов «с конца» нет (это не Python): хочешь последний — `xs[xs.len - 1]`, и обязательно убедись, что `len > 0`.
