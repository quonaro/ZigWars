## Задание

Реализуй `renderTable` — рендер ASCII-таблицы из пар «ключ-значение» в строку.

```zig
pub fn renderTable(alloc: std.mem.Allocator, rows: []const [2][]const u8) ![]u8
```

### Формат строки

Каждая строка:

```
<ключ, дополненный пробелами справа до ширины max_key_len> | <значение>\n
```

- `max_key_len` — максимальная длина ключа (`r[0]`) среди всех строк.
- После ключа — разделитель `" | "`, затем значение и `\n`.
- Пустой `rows` → пустая строка `""`.

### Пример

```zig
rows = .{
    .{ "name", "zig" },
    .{ "ver", "0.17" },
}
```

```
name | zig
ver  | 0.17
```

`"name"` длиннее `"ver"` на 1 → `ver` дополняется одним пробелом перед `|`.

### Требования

- Используй `std.Io.Writer.Allocating` — собери всё в него и верни через `toOwnedSlice()`.
- Возвращаемый срез принадлежит вызывающему (тест освобождает `alloc.free`).
- Выравнивание ключей делай вручную (подсчитай `max_key_len` и допиши пробелы) или через `{s:<N}` — но `N` должна быть comptime-константой, поэтому проще вручную.
