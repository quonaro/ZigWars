## Задание

```zig
pub fn countLines(io: std.Io, alloc: std.mem.Allocator, path: []const u8) !usize
```

Верни число строк в файле по определению:

> **lines = (число `\n` в файле) + 1, если файл не пуст и не заканчивается на `\n`**

### Таблица

| Содержимое | Строк |
|------------|-------|
| `""` | 0 |
| `"a"` | 1 |
| `"a\n"` | 1 |
| `"a\nb"` | 2 |
| `"a\nb\n"` | 2 |
| `"a\n\n"` | 2 |
| `"\n"` | 1 |
| `"\n\n\n"` | 3 |
| `"x\ny\nz"` | 3 |

### Правила

- Читай файл через `cwd.readFileAlloc` с лимитом `.limited(1 << 20)`, освобождай память.
- Ошибки чтения пробрасывай (`try`).
- `std.mem.count(u8, data, "\n")` — готовый подсчёт разделителей.

### Проверь края

- Пустой файл → `0`, не `1`.
- Файл вида `"a"` (без `\n`) → `1`.
- `"a\n\n"` → `2` (две `\n`, плюс ничего после последней).
