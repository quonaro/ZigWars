## Задание

Безопасное деление целых:

```zig
pub fn safeDiv(a: i32, b: i32) ?i32
```

Если `b == 0` — вернуть `null`. Иначе — результат деления с усечением к нулю (как в C): `@divTrunc(a, b)`.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `safeDiv(10, 2)` | `5` |
| `safeDiv(-7, 2)` | `-3` — усечение к нулю, не к −∞ |
| `safeDiv(7, -2)` | `-3` |
| `safeDiv(10, 0)` | `null` |
| `safeDiv(0, 5)` | `0` |

Не используй `/` для `i32` — Zig не даст (неоднозначность округления). Только `@divTrunc`.
