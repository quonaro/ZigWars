## Задание

Реализуй два способа распаковать `?i32`:

```zig
pub fn unwrapOr(x: ?i32, default: i32) i32
pub fn unwrapPanic(x: ?i32) i32
```

- `unwrapOr` — значение из `x`, а если `x == null` — `default`.
- `unwrapPanic` — значение из `x`; при `null` будет panic (оператор `.?` сделает это сам, ничего проверять не надо).

### Примеры

| Вызов | Результат |
|-------|-----------|
| `unwrapOr(42, -1)` | `42` |
| `unwrapOr(null, -1)` | `-1` |
| `unwrapOr(0, 99)` | `0` — ноль это значение, не «пусто»! |
| `unwrapPanic(7)` | `7` |

`unwrapPanic(null)` в тестах не вызывают — она падает намеренно.
