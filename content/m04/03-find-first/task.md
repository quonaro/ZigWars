## Задание

Найди первый элемент слайса, для которого предикат вернёт `true`:

```zig
pub fn findFirst(xs: []const i32, pred: fn(i32) bool) ?i32
```

`pred` — это функция, которую вызывают как `pred(x)`. Нашёл — верни сам элемент. Не нашёл никого (или слайс пуст) — `null`.

### Примеры

```zig
fn isEven(x: i32) bool { return @rem(x, 2) == 0; }
fn isBig(x: i32) bool { return x > 100; }
```

| Вызов | Результат |
|-------|-----------|
| `findFirst(&[_]i32{1,3,4,6}, isEven)` | `4` — первый чётный, не последний |
| `findFirst(&[_]i32{1,3,5}, isEven)` | `null` |
| `findFirst(&[_]i32{200,1,300}, isBig)` | `200` |
| `findFirst(&[_]i32{}, isEven)` | `null` |

Верни именно элемент (`?i32`), а не его индекс.
