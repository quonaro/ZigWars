## Задание

Две функции про optional-трансформации.

```zig
pub fn firstVowel(s: []const u8) ?u8
```

Первый байт строки, который является строчной латинской гласной (`a`, `e`, `i`, `o`, `u`). Нет гласных или строка пуста — `null`. Заглавные не считаются.

```zig
pub fn optChain(a: ?i32) ?i32
```

Если `a` содержит значение — вернуть его, умноженное на 2. Если `a == null` — вернуть `null`.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `firstVowel("zig")` | `'i'` |
| `firstVowel("hello")` | `'e'` — первая по порядку |
| `firstVowel("bcdfg")` | `null` |
| `firstVowel("")` | `null` |
| `firstVowel("APPLE")` | `null` — заглавные не гласные |
| `optChain(21)` | `42` |
| `optChain(null)` | `null` |

Байты сравнивай с литералами символов: `c == 'a'` и т.д. Или `switch`.
