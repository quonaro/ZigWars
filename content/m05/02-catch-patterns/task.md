## Задание

Парсинг строки в число с запасным планом через `std.fmt.parseInt(i64, s, 10)`:

```zig
pub fn parseOr(s: []const u8, default: i64) i64
pub fn parseOrZero(s: []const u8) i64
```

- `parseOr` — число из строки; при любой ошибке парсинга — `default`.
- `parseOrZero` — то же, но `0`. Реализуй её **через `parseOr`** — одна строка.

`parseInt` вернёт ошибку на мусоре, пустой строке и переполнении `i64`.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `parseOr("42", -1)` | `42` |
| `parseOr("abc", -1)` | `-1` |
| `parseOr("-7", 0)` | `-7` — минус парсится |
| `parseOr("", 5)` | `5` |
| `parseOr("99999999999999999999", 7)` | `7` — переполнение |
| `parseOrZero("0")` | `0` |
| `parseOrZero("x")` | `0` |
