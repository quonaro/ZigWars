## Задание

Смоделируй операцию, которая «захватывает ресурс» и может провалиться. В модуле уже есть глобальный счётчик откатов и хелперы для тестов:

```zig
var rollbacks: usize = 0;

pub fn rollbackCount() usize { ... }  // сколько раз сработал откат
pub fn resetRollback() void { ... }   // обнулить счётчик

pub fn riskyOp(fail: bool) !void
```

`riskyOp` должен:

1. «Захватить ресурс» — и объявить `errdefer rollbacks += 1;`
2. Если `fail == true` — вернуть `error.SimulatedFailure` (при этом счётчик вырастет на 1).
3. Если `fail == false` — успешно завершиться (счётчик НЕ трогается — ресурс «живёт» у вызывающего).

### Примеры

| Вызов | Результат | `rollbackCount()` после |
|-------|-----------|--------------------------|
| `riskyOp(false)` | успех | `+0` |
| `riskyOp(true)` | `error.SimulatedFailure` | `+1` |
| `riskyOp(true)` ×3 | три ошибки | `+3` |

Главное — `errdefer`, а не `defer`: счётчик растёт только на пути ошибки.
