# `errdefer` — уборка только при провале

## Два брата: `defer` и `errdefer`

`defer` ты знаешь: выполняется при выходе из блока — и по успеху, и по ошибке. `errdefer` — его разборчивый брат: выполняется **только если блок покидается по ошибке**.

```zig
fn install() !void {
    const file = try open();       // может упасть — errdefer ниже ещё не объявлен, выходим чисто
    errdefer file.close();         // закроем ТОЛЬКО если дальше упадём

    const buf = try alloc();       // упало? сработает errdefer выше — файл закроется
    errdefer free(buf);

    try writeAll(file, buf);       // упало? закроется и буфер, и файл
    // успех: errdefer-ы НЕ выполнились, ресурсы живут и уходят вызывающему
}
```

Порядок — LIFO, как у `defer`: объявленный последним срабатывает первым.

## Зачем это нужно

Классическая ситуация — **частичная инициализация**: объект собирается по кускам, на каждом шаге может упасть, и надо откатить уже сделанное. Без `errdefer` это лес ручных `catch { cleanup(); return err; }`. С ним — одна строчка сразу после захвата ресурса.

Аналоги: C++ RAII делает это деструкторами (неявно), Go — только `defer` (приходится проверять `err != nil` вручную), Zig явно разделяет два пути выхода.

## Правило размещения

`errdefer` ставят **сразу после** успешного получения ресурса и **до** первого `try`, который может бросить. Логика простая: объявленный `errdefer` защищает всё, что ниже. Объявил до `try` открытия файла — при неудаче открытия он не выполнится (и правильно: закрывать нечего).

```zig
var f = try open();
errdefer f.close();   // ← здесь, а не выше и не ниже по тексту «для красоты»
```

## Откат состояния, а не только ресурсов

`errdefer` — произвольный код, не только `close`/`free`. Счётчики, транзакции, временные записи в мапе:

```zig
counter += 1;
errdefer counter -= 1;   // упали — как будто нас не было
```

## Частая пара: `defer` + `errdefer`

```zig
var gpa = ...;
defer gpa.deinit();                 // всегда — логирование, метрики
errdefer rollbackState();           // только при провале — откат
```

`defer` для «убрать за собой в любом случае», `errdefer` для «вернуть как было, если не вышло».
