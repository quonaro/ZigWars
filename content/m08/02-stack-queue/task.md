## Задание

Реализуй `evalRPN` — вычислитель выражения в обратной польской нотации.

```zig
pub fn evalRPN(alloc: std.mem.Allocator, tokens: []const []const u8) !i64
```

`tokens` — последовательность токенов: числа (возможно отрицательные) и операторы `"+"`, `"-"`, `"*"`, `"/"`. Деление — `@divTrunc` (усечение к нулю). Стек — `std.ArrayList(i64)` на переданном аллокаторе.

### Ошибки (возвращай, не паникуй)

- `error.InvalidExpression` — оператору не хватило операндов, в конце на стеке не одно число, вход пустой.
- `error.DivisionByZero` — деление на ноль.
- Ошибки `parseInt` пробрасывай как есть.

### Примеры

| `tokens` | Результат |
|----------|-----------|
| `["2","1","+","3","*"]` | `9` — (2+1)·3 |
| `["4","13","5","/","+"]` | `6` — 4 + 13/5 |
| `["10","6","9","3","+","-11","*","/","*","17","+","5","+"]` | `22` |
| `["5"]` | `5` |
| `["4","0","/"]` | `error.DivisionByZero` |
| `["+"]` | `error.InvalidExpression` |
