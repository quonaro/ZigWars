## Задание

Реализуй `twoSum` — классическую задачу за O(n) через хеш-таблицу.

```zig
pub fn twoSum(alloc: std.mem.Allocator, xs: []const i32, target: i32) !?[2]usize
```

Найди два различных индекса `i` и `j` таких, что `xs[i] + xs[j] == target`, и верни `.{i, j}` с `i < j`. Если пары нет — `null`. Если пар несколько — достаточно любой, но тесты проверяют конкретные случаи: иди слева направо, ищи для каждого `xs[i]` уже встречавшийся партнёр `target - xs[i]` в мапе — тогда найденная пара всегда «ранний + поздний» индексы.

### Правила

- `std.AutoHashMap(i32, usize)` для «значение → индекс».
- Один проход: проверка партнёра → `put` текущего.
- `deinit` мапе.

### Примеры

| `xs` | `target` | Результат |
|------|----------|-----------|
| `[2, 7, 11, 15]` | `9` | `.{0, 1}` |
| `[3, 2, 4]` | `6` | `.{1, 2}` |
| `[3, 3]` | `6` | `.{0, 1}` |
| `[1, 5, 9]` | `100` | `null` |
