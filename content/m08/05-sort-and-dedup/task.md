## Задание

Реализуй `uniqueSorted` — копию `xs` без дубликатов, отсортированную по возрастанию.

```zig
pub fn uniqueSorted(alloc: std.mem.Allocator, xs: []const i32) ![]i32
```

### Правила

- Результат — свежий срез из `alloc`, владение у вызывающего.
- Вход `xs` не мутируй — сделай копию (`alloc.dupe`), сортируй её.
- Сортировка: `std.mem.sort(i32, items, {}, lessThan)` с компаратором `fn (void, i32, i32) bool`.
- Дедупликация — in-place «two pointers», потом подрежь буфер до фактической длины (`alloc.realloc` или свежий `alloc` + `@memcpy` + `free`): `free` результата должен получить срез корректной длины.
- Пустой вход → пустой срез.

### Примеры

| `xs` | Результат |
|------|-----------|
| `[4, 2, 4, 1, 2]` | `[1, 2, 4]` |
| `[7, 7, 7]` | `[7]` |
| `[]` | `[]` |
| `[3, 1, 2]` | `[1, 2, 3]` |
