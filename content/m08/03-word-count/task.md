## Задание

Реализуй `wordCount` — количество **уникальных** слов в строке.

```zig
pub fn wordCount(alloc: std.mem.Allocator, s: []const u8) !usize
```

Слово — последовательность не-разделителей; разделители: пробел, табуляция, перевод строки (`" \t\n"`). Регистр учитывается: `"Zig"` и `"zig"` — разные слова.

### Правила

- Используй `std.StringHashMap(void)` как множество.
- Для разбиения — `std.mem.tokenizeAny(u8, s, " \t\n")`.
- Ключи — подстроки `s`, `dupe` не нужен (входные данные переживают мапу).
- Мапу не забудь `deinit()`.

### Примеры

| `s` | Результат |
|-----|-----------|
| `"hello world hello"` | `2` |
| `""` | `0` |
| `"a a a a"` | `1` |
| `"zig is fun"` | `3` |
| `"x  \t y\nx"` | `2` |
