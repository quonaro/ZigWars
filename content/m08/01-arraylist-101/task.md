## Задание

Реализуй `squares` — список квадратов `0..n`, собранный через `std.ArrayList`.

```zig
pub fn squares(alloc: std.mem.Allocator, n: usize) ![]u64
```

Элемент `i` результата равен `i * i` (тип `u64`).

### Правила

- Используй `std.ArrayList(u64)` — `.empty`, `append(alloc, x)`, `toOwnedSlice(alloc)`.
- Вернувшийся срез принадлежит вызывающему (тест освободит через `alloc.free`).
- `n = 0` → пустой срез.
- Следи за типами: `i` имеет тип `usize`, результат — `u64`, понадобится `@intCast`/`@as`.

### Примеры

| Вызов | Результат |
|-------|-----------|
| `squares(a, 5)` | `[0, 1, 4, 9, 16]` |
| `squares(a, 0)` | `[]` |
| `squares(a, 11)` | `[0, 1, 4, ..., 100]` |
